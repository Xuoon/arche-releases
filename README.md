# ARCHE für Windows

Installer und Updates des ARCHE-Clients. Die neueste Version steht unter
[Releases](https://github.com/Xuoon/arche-releases/releases/latest):
`ARCHE-win-Setup.exe` installiert das Spiel, danach aktualisiert es sich
beim Start selbst. `ARCHE-win-Portable.zip` läuft ohne Installation.

Die Pakete baut und veröffentlicht die CI des Spiels, dieses Repo enthält
keinen Quelltext.
